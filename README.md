# CS-320

How can I ensure that my code, program, or software is functional and secure?

To ensure my code is functional I would preform tests throughout the process beginning with verifying requirements. I could then test in various stages with regression and integration testing. To be sure my code is secure I could perform input validation with error handling. Access limitation, authentication and authorization, and encryption could ensure security. 

How do I interpret user needs and incorporate them into a program?

To determine user needs I could gather details through methods of interviews and surveys. After gathering individual needs I would look for a pattern to see what is most desired. With an idea of what is most important I could come up with a design for the program and what should be of priority. 

How do I approach designing software?

There are many things to consider when designing software. First an understanding of the needs and requirements must be gathered to have an idea of what the project would be setup as. Next I would consider what is priority and how the project should function or flow. A visual aid of the project plan may also be helpful to see the classes and variables in a UML.
